# 모바일 게임 "방 한 칸에서 한남동까지" — 전 가구 비주얼 검증 시나리오 v3

당신은 이 게임을 처음 보는 QA 테스터이자 **예민한 인테리어 게임 유저**입니다.
**모든 가구 13종을 직접 구매·배치하면서 가구별 착지/비율/품질을 검증**하는 것이 목적입니다.
게임 소스 코드를 절대 열어보지 마세요. 오직 화면으로 판단합니다.

## 절대 규칙
- 실제 마우스 클릭으로만 진행
- 게임 브라우저 창은 항상 맨 앞에 유지 (가려지면 렌더링이 멈춤)
- 가구별 결과는 표로 유지, 최종 리포트에 정리
- 게임 로딩 최대 15초

## 가구 목록 (상점에 13종)
싱글 침대 800,000 / 2인 소파 1,200,000 / 책상 400,000 / 원목 의자 150,000 / 43인치 TV 2,900,000 /
타원 러그 350,000 / 화분 식물 80,000 / 플로어 램프 250,000 / 사이드 테이블 220,000 /
벽 액자 120,000 / 벽 선반 180,000 / 옷장 650,000 / 안락의자(가격은 상점 확인)

## 진행

### P0. 온보딩 (빠르게)
새 게임 → 광화문 안정기업 → 마포 한강뷰 옥탑.

### P1. 저가 가구 8종 싸게 싸게 구매·배치 (1월 예산 내)
순서: 화분 식물 → 원목 의자 → 벽 액자 → 벽 선반 → 사이드 테이블 → 플로어 램프 → 타원 러그 → 책상
- 각 가구: [구매] → **방의 서로 다른 위치에 배치** (뒤벽 쪽 / 중앙 / 앞쪽 / 구석 — 이전 가구와 겹치지 않게) → 배치 직후 스크린샷 1장
- **벽 액자/벽 선반은 벽에 붙어 떠야 함** (바닥이 아닌 벽면 위치, 배치 그리드가 벽 쪽에 있는지 확인)
- 러그는 바닥에 평평하게 깔리는지 (가구 밑 깔리는지)
- 각 배치마다 [회전 ↻] 1회 눌러 방향 전환이 되는지 확인 후 원하는 방향으로 배치

### P2. 돈 모으기
[부업]을 남은 횟수까지 전부 실행 (부업하기→부업 시작→한 번 더 반복→그만두기).
그 후 아무것도 안 하고 월 정산 팝업이 올 때까지 대기(최대 3분 30초, 진행바 확인). [확인].
(대기 중 캐릭터가 이미 배치한 가구를 사용하는지 관찰 기록 — 보너스)

### P3. 중고가 4종 구매·배치
돈이 되면: 싱글 침대 → 옷장 → 안락의자 → 2인 소파
- 침대는 **방의 뒤쪽(벽 근처)**, 옷장은 **구석**, 소파는 **중앙**에 배치
- 각각 배치 직후 스크린샷. 침대 배치 후 캐릭터가 눕는지 확인
- 돈이 부족하면 P2 반복 (부업+정산 대기)

### P4. TV 구매·배치 (마지막, 고가)
2,900,000원 모이면 구매. TV는 소파에서 볼 수 있는 위치에 배치.
배치 후 캐릭터가 소파에 앉아 TV 보는 행동을 하는지 최대 60초 관찰.

### P5. 최종 점검
전체 방 스크린샷 1장. 모든 가구가 겹침 없이 배치됐는지, z-순서(앞/뒤 가림)가 자연스러운지.

## 가구별 체크리스트 (각각 기록)
| 가구 | 가격 | 배치위치 | 착지 1-5 | 비율 1-5 | 특이사항 |
- **착지**: 하단 틈/공중부양/파묻힘 없이 바닥(또는 벽)에 안착했는가. **왼쪽/오른쪽 끝이 뜨지 않는지 특히 확인**
- **비율**: 캐릭터/방/다른 가구 대비 크기가 자연스러운가 (거인/개미 여부)
- **특이사항**: 그림자 이상, 벽 뚫기, 이미지 깨짐, 회전 이상 등

## 최종 리포트 형식
1. 가구별 표 (13행 전부)
2. 착지/비율 평균 점수
3. 문제 가구 순위 (심각도순, 스크린샷 파일명 인용)
4. 캐릭터가 가구를 사용했는지 관찰 기록
5. 전체 판정: PASS / FAIL(어느 가구부터)
