# 모바일 게임 "방 한 칸에서 한남동까지" — 수동 QA 시나리오 v2 (디테일 강화판)

당신은 이 게임을 처음 보는 QA 테스터이자 **예민한 모바일 게임 유저**입니다.
기능이 동작하는지만 보지 않고, 실제 유저가 손가락으로 만졌을 때 느낄 **이미지·시간·움직임·비율·착지감**까지 평가합니다.
**게임 소스 코드를 절대 열어보지 마세요.** 오직 화면으로 판단합니다.

## 평가 규칙

- 각 단계는 [PASS/FAIL] + **품질점수 1~5** (5=출시급, 3=평범, 1=즉시 수정 필요) + 한줄 근거
- "이건 유저가 불편할 만한데?" 하는 느낌적 느낌도 감점 사유로 기록
- 에러/멈춤/깨진 화면/클릭 3회 이상 무반응 → 즉시 중단 후 리포트
- 게임 로딩 최대 15초 기다릴 것

## 게임 소개 (기대감정)

서울 첫 직장인이 되어 첫 집을 구하고, 월급 받으며 가구를 하나씩 사서 방을 채우는 힐링 게임.
핵심 재미: 사고 싶은 가구 → 돈 조금 부족 → 기다리기/부업 → 구매 → 방이 좋아지고 캐릭터가 실제로 그 가구를 사용. **"내 방"이 되어가는 만족감.**

---

# A. 온보딩

### S1. 표지
[행동] 게임 로드 → [새 게임] 클릭
[기대] 예쁜 일러스트 표지, 제목 "방 한 칸에서 한남동까지", 가진 돈 4,500,000원 표시.
[디테일] ▸ 로딩 시간이 15초 안인가 ▸ 표지 이미지가 흐릿하거나 깨지지 않았는가 ▸ 버튼을 누르면 **눌렸다는 시각 피드백**(살짝 작아짐 등)이 있는가

### S2. 첫 직장 선택 → 광화문 안정기업
[기대] "첫 직장을 선택하세요" + 3개 선택지(광화문 300만·부업6 / 구로 330만·5 / 강남 370만·3).
[디테일] ▸ 선택지 3개의 그림/텍스트 간격이 균등한가 ▸ 글씨 크기가 휴대폰에서 읽기 충분한가

### S3. 첫 집 선택 → 마포 한강뷰 옥탑
[기대] 4개 매물(관악신림 55만/55분, 관악신축 70만/50분, 구로직주근접 65만/15분, 마포옥탑 85만+6만/40분).
[디테일] ▸ 월세·통근 정보가 한눈에 비교되는가 ▸ 숫자에 3자리 콤마가 있고 잘못 읽힐 여지가 없는가

# B. 입주와 방

### S4. 입주 직후 (10초 관찰)
[기대] 빈 원룸 + 캐릭터 서 있음. HUD: "1월차 · 계약 24개월 · 보유 4,500,000원 · 사용 가능 2,290,000원" + 체력/스트레스/행복. 우측 "지금 갖고 싶어요 (1/5)" 침대 패널. 하단 [가구 상점][보관함][부업]. HUD 아래 얇은 시간 진행바.
[디테일 — 비율/이미지 핵심] ▸ **캐릭터 크기가 방에 비해 자연스러운가**(너무 큰 거인/작은 개미 아닌지) ▸ 캐릭터가 **바닥에 발이 닿아 서 있는가**(공중 부양 아닌지) ▸ 방 원근(아이소메트릭)이 어색하게 찌그러져 있지 않은가 ▸ 캐릭터가 잠깐 서성이면 걷기 애니메이션(다리/팔 움직임)이 있는가, 방향을 바꿔 왼쪽을 볼 때 좌우 반전이 자연스러운가
[디테일 — 시간] ▸ 진행바가 눈에 띄게 차오르는가(1게임월=현실 3분) ▸ 캐릭터 머리 위 말풍선이 뜨면 HUD에 가려지지 않는가

# C. 구매와 배치 (핵심)

### S5. 가구 상점
[행동] [가구 상점] 클릭
[기대] 카드 13종(러그/침대/소파/의자/TV/램프/액자/선반/안락의자/사이드테이블/책상/식물/옷장)이 가격과 함께 **전부 한 화면에** 보이고 "사용 가능 2,290,000원" 표시.
[디테일] ▸ 카드 아이콘들이 **하나의 그림체**로 통일됐는가(하나만 튀지 않는지) ▸ 가격이 배경색 대비로 또렷한가 ▸ 상점을 열어도 시간 진행바가 계속 가는지(설정상 쇼핑 중에도 시간은 흐름)

### S6. 싱글 침대(800,000원) 구매
[행동] 침대 [구매] 클릭
[기대] 상점 닫힘 + 바닥에 흰 다이아몬드 그리드 + 반투명 초록 침대(고스트). 하단 [회전 ↻][보관함에 넣기][취소 (환불)] + "빈 칸을 눌러 배치". "-800,000원" 금액이 떠오름.
[디테일] ▸ 금액 플로팅이 사라지기 전에 충분히(1초 이상) 읽히는가 ▸ **시간 진행바가 멈췄는가**(배치 중엔 시간 정지가 기획)

### S7. 배치 (마우스를 바닥 이곳저곳 이동 → 빈 칸 클릭)
[기대] 고스트가 **커서 정확히 아래** 따라옴(왼쪽 위로 치우침 없음). 가능=초록/불가=빨강. 클릭 시 배치 확정, 그리드 사라짐.
[디테일 — 착지 핵심] ▸ 배치된 침대가 **바닥에 착지**했는가(다리/그림자와 바닥 사이 틈, 공중 부양 없는지) ▸ 침대 크기가 방/캐릭터 대비 자연스러운가 ▸ 침대가 벽을 뚫거나 창문 위에 어색하게 걸치지 않는가 ▸ 배치 확정 클릭 좌표 기록
[실패 정의] 에러/멈춤/검은화면/고스트-실배치 위치 불일치

### S8. 캐릭터 반응 (최대 45초 관찰)
[기대] ① "소원이 이뤄졌어요! ♥ 잠자리 완성!" 팝업 → [좋아!] ② 캐릭터가 **걸어서**(4프레임 다리 움직임) 침대로 감 ③ 침대에 **옆으로 누워** "Zzz… 잠자는 중" 말풍선 ④ 사용 끝나면 **다른 행동으로 이동**(같은 자세에 갇히면 결함!) ⑤ 몸이 매트리스 위에 정확히 얹히는가(바닥에 겹치거나 침대 위에 떠 있지 않은지)
[디테일] ▸ 말풍선이 캐릭터를 따라다니는가 ▸ 걷는 속도가 자연스러운가(순간이동 아님) ▸ 행동 바뀔 때 "행복 +N" 같은 플로팅이 뜨는가

### S9. 부족액 → 부업
[행동] [가구 상점] → 43인치 TV(2,900,000원) [구매]
[기대] "N원이 부족해요" 팝업 + [부업하기] + [다음 월급까지 기다리기]. [부업하기]→[부업 시작]→"일 끝! +158,000원"(월 여유 79만의 20% 기준, 월이 넘어갔다면 다를 수 있음)→[그만두기].
[디테일] ▸ 부업 보상 금액이 크고 초록색으로 강조되는가 ▸ 부업 카운트(1/6회)가 보이는가

### S9b. 상점 열어둔 채 월 정산 (3분 30초 대기)
[행동] 상점을 연 채 대기 (30초마다 스크린샷 1장)
[기대] ① 진행바가 차오르다가 "N월이 되었어요" 정산 팝업이 **상점을 닫지 않고 위에 겹쳐** 뜸 ② 팝업이 뜬 직후(0.5초 내) 아무데나 클릭 → **팝업이 무시됨**(스친 클릭 방지) ③ [확인] 클릭 → **상점이 그대로 복원**되고 카드 [구매] 클릭이 계속 작동 ④ 정산 내역에 이벤트 비용이 있으면 "(-30,000원)"처럼 표시
[디테일] ▸ 정산 팝업의 월급/지출/부업/스탯이 읽기 쉽게 정렬됐는가 ▸ [확인] 누르기 전에 시간이 멈춰 있는가

### S10. 소파 구매 → 회전/취소 안전성
[행동] 상점 → 2인 소파(1,200,000원) [구매] → [회전 ↻] 2번 → 바닥 호버 → [취소 (환불)]
[기대] 회전할 때마다 고스트 방향/발판이 바뀜. 취소 시 환불 토스트 + 잔액 복구 + 그리드 정리.
[디테일] ▸ 회전이 즉각 반응하는가 ▸ 취소 후에도 시간 진행바가 다시 가는가 ▸ 환불 후 다시 다른 가구 구매가 말끔히 되는가

### S11. 자율생활 장기 관찰 (2분)
[행동] 아무것도 건드리지 말고 2분 관찰 (30초마다 스크린샷)
[기대] 캐릭터가 스스로 행동을 바꿈: 서성→침대 수면→일어나 다른 곳→(가구가 침대뿐이면 배회/스트레칭도 OK). 같은 자세에 1분 이상 갇히면 결함.
[디테일] ▸ 사용 중 미세한 호흡(위아래 흔들림)이 있는가 ▸ 이동 중 캐릭터와 침대의 **겹침 순서**(앞/뒤)가 자연스러운가 ▸ 말풍선 텍스트가 상황과 맞는가

### S12. 최종 판정
전 단계 [PASS/FAIL] + 품질점수 + **"출시해도 되는가" 한줄 총평** + 수정이 필요한 것 우선순위 3개.
